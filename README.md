# Генератор презентаций и рефератов

Адаптивный инструмент для создания учебных документов для студентов **Тверского филиала РГУ им. А.Н. Косыгина (Технологии. Дизайн. Искусство)**.

## Возможности

- **Презентации (.pptx)** — стильный дизайн с автоматическим подбором цветовой темы под название
- **Рефераты (.docx)** — оформление по ГОСТ 7.32-2017, готовый титульный лист с данными филиала

## Установка зависимостей

```bash
pip install python-pptx python-docx Pillow
```

## Использование

### Презентация
```bash
python generator.py presentation "Нейронные сети" --author "Иванов И.И." --group "ИТ-101" --discipline "Информатика"
```

### Реферат
```bash
python generator.py referat "Основы экологии" --author "Петров П.П." --group "ИТ-101" --discipline "Экология" --supervisor "Иванова Е.П."
```

### Посмотреть доступные темы дизайна
```bash
python generator.py themes
```

## Адаптивные темы презентаций

Тема дизайна определяется **автоматически** по ключевым словам в названии, или задаётся вручную через `--theme`:

| Ключ | Описание | Стиль |
|------|----------|-------|
| `tech` | Технологии / IT / Программирование | Тёмный + неоновые акценты |
| `humanities` | Гуманитарные / История / Философия | Тёплый / светлый |
| `science` | Естественные науки / Физика / Химия | Тёмный + зелёные акценты |
| `art` | Искусство / Дизайн / Текстиль | Тёмный + розовые акценты |
| `business` | Экономика / Бизнес / Менеджмент | Светлый / строгий |
| `minimalist` | Универсальная (по умолчанию) | Белый / чёрный |

## Параметры

### Общие
| Параметр | Описание |
|----------|----------|
| `--author` | ФИО автора |
| `--group` | Номер группы |
| `--discipline` | Название дисциплины |
| `--department` | Кафедра |
| `--output`, `-o` | Имя выходного файла |

### Только для презентаций
| Параметр | Описание |
|----------|----------|
| `--slides` | Количество слайдов (по умолчанию 8) |
| `--subtitle` | Подзаголовок |
| `--theme` | Тема дизайна (tech/humanities/science/art/business/minimalist) |

### Только для рефератов
| Параметр | Описание |
|----------|----------|
| `--supervisor` | ФИО преподавателя |
| `--supervisor-title` | Должность преподавателя |

## Оформление реферата (ГОСТ 7.32-2017)

- Шрифт: Times New Roman 14pt
- Поля: левое 30мм, правое 15мм, верхнее и нижнее 20мм
- Межстрочный интервал: 1.5
- Абзацный отступ: 1.25 см
- Титульный лист с полным названием филиала

## Шрифты для презентаций

Для максимальной стильности рекомендуется установить на компьютере:
- **Montserrat** — [Google Fonts](https://fonts.google.com/specimen/Montserrat)
- **Roboto** — [Google Fonts](https://fonts.google.com/specimen/Roboto)
- **Raleway** — [Google Fonts](https://fonts.google.com/specimen/Raleway)
- **Open Sans** — [Google Fonts](https://fonts.google.com/specimen/Open+Sans)
- **Lato** — [Google Fonts](https://fonts.google.com/specimen/Lato)

Если шрифтов нет, PowerPoint автоматически подставит fallback (Calibri/Arial).
